Compose ton set avec le butin de Hyjal et du Black Temple, puis envoie-le dans WoWSims pour le tester. Chaque liste est triée par ta priorité (🥇🥈🥉, ○ = ouvert MS > OS, – = autres classes prio), les jetons T6 apparaissent directement en pièce de ta classe, et le menu « Objets » (Tank, DPS physique, DPS sorts, Soins — d'après les stats réelles) écarte ce qui ne concerne pas ton rôle. Les objets purement endurance/résistances restent toujours visibles.

— Ouvrir dans WoWSims avec ce stuff

Le bouton ouvre le simulateur avec l'équipement chargé, et copie le JSON ci-dessous en même temps. Autre chemin : Import → 60U TBC → Ctrl+V → Import.

Si les emplacements restent vides quoi qu'on fasse, le simulateur garde en mémoire un réglage cassé (laissé par une ancienne version de ce lien) : dans WoWSims, clique la roue dentée ⚙️ en haut à droite → Restore Defaults, recharge la page, puis réimporte. À faire une seule fois.

L'import remplace tout l'équipement du simulateur : les emplacements laissés vides ici arrivent vides là-bas. Complète-les dans WoWSims avant de simuler, sinon le résultat ne veut rien dire.

Garder tes talents et réglages. Dans WoWSims, règle une fois ton personnage (talents, conso, buffs, cible…), puis Export → Link → Copy et colle le lien ici. Le bouton ouvrira ensuite ta simulation avec le stuff choisi : gemmes et enchantements gardés sur les pièces inchangées, et les emplacements vides gardent tes pièces actuelles. À refaire seulement quand tu changes tes réglages.

Priorités reprises telles quelles du Google Sheet de la guilde ; les classes affichées sont déduites du texte de priorité (« Enhance » → Chaman Amélioration, « RSHAM » → Chaman Restauration, etc.). Les jetons T6 listent les trois classes qui peuvent les utiliser, même si la priorité n'en nomme que deux ; côté EDEN, le jeton Vanquisher est prioritaire pour le Druide Farouche DPS et Tank, à égalité. En cas de doute, la colonne « Priorité » du sheet fait foi.
